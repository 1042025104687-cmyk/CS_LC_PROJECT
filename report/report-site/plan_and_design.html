Chosen Project

I will develop a Forest Fire Prevention System that uses micro:bit data to detect environmental conditions indicative of drought or wildfire risk.

The system reads temperature and light levels, calculates a risk score via a python script, and provides user feedback to demonstrate how embedded systems can address climate-related environmental threats.

Alternative Options

Criteria Forest Risk Prevention (Chosen) Drought/Flooding Detection System
Sensors Used Temperature + Light Moisture + Temperature
Model Type Weighted linear wildfire risk score Threshold-based irrigation trigger
What-If Potential Stress tests and multi-day trend simulations Limited — binary wet/dry outcome
Brief Alignment Directly addresses wildfire and climate threats to forests Directly relates to biodiversity and ecosystems

I chose the Forest Risk Prevention System for three reasons. First, I do not have access to moisture checking hardware. Second, what-if models are easier to build for this system. Third, it fits better with the brief.

Stakeholder Needs

Environmental Monitors

Need an early warning system to detect dangerous conditions before they escalate.

Local Communities

Need awareness of environmental risks like drought and wildfire that threaten safety.

End User

Requires a simple interface showing readings, risk levels, and actionable advice.

Teacher or Examiner

Must see that the project integrates an embedded system, computer model, and feedback loop.

Design Plan

  1. Manual start/auto operation — Start via button; system runs autonomously (BR3).
  2. Analogue sensor input — Read temperature and light from micro:bit (BR2).
  3. Data logging — Save timestamped readings to CSV for review (BR5).
  4. Simulation scenarios — 7 scenarios testing varied conditions (BR6).
  5. Risk scoring — 0–100 score using a weighted formula (AR1).
  6. What-if analysis — Stress and trend tests to predict outcomes (AR2).
  7. Adaptive escalation — Adjust sensitivity based on sustained risk (AR3).
  8. Visual/Audio feedback — LED patterns and sounds for risk levels (BR4).

Technologies Used

Python/Tkinter

Logic and multi-tab GUI (Dashboard, Graphs, Alerts, Settings).

BBC Micro:bit

Embedded device for sensor input and LED/audio output.

PySerial

Manages USB communication between micro:bit and desktop app.

Pandas/NumPy

Handles CSV operations and numerical model calculations.

Persistent Data Storage

JSON for configuration; CSV for session data logging.
