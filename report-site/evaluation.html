Analysis of Project Brief

My initial objectives of making a Forest Risk Prevention System with a micro:bit having temperature and light levels sensor input, calculating a risk score via a computer program, and providing user feedback I consider achieved. Thus showing I did make an adaptive system.

Building the weighted linear model taught me how to visualize data and set thresholds.

If I did this again, I would plan the micro:bit feedback from the start to avoid having to change things later. I would also create a full test plan earlier.

This working project shows embedded systems and adaptive algorithms can model real environmental threats like wildfires.

Future Improvements

One improvement I could make is to use a weather API like Open-Meteo to get real wind data making my system more reactive and accurate.

Another improvement I could have made is to put create a web interface for universal access, currently my system is restricted to desktop use. This would make the system a lot more accessible and easier to use.

One change I would have made was to use less simulated data and more real-world data by utilizing external data sources for more informative results (E.G Kaggle) .

Reflection

I'm rather satisfied with the final artifact, I included all aspects of both the Advanced and Basic requirements to my final artefact, although having to adjust my approach. I mistakenly started making the micro:bit controller in block code. I eventually converted to micropython to create a well-functioning system.

My project shows how computer science can be used to address real-world problems like wildfires whilst also demonstrating the importance of planning, testing, and iterating in the development process.
